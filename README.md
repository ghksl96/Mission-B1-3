# [프로젝트 1] 노코드 자동화 도구 비교 분석 보고서


## 1. 프로젝트 개요
구글 스프레드시트에 입력된 고객 문의 데이터의 유형(긴급/일반)을 판별하여, 각기 다른 이메일 응답을 자동으로 발송하는 워크플로우를 구축하고, 이를 서로 다른 두 가지 자동화 도구(Make, Zapier)로 구현하여 비교 분석하는 것을 목적으로 합니다.

### 워크플로우 구조
- **Trigger**: Google Sheets - 새로운 행(Row)이 추가될 때 실행
- **Condition (Filter/Router)**: 
    - '문의유형' 열의 값이 **'긴급'**인 경우 Path A 실행
    - '문의유형' 열의 값이 **'일반'**인 경우 Path B 실행
- **Action**: Gmail - 각 유형에 맞는 맞춤형 안내 메일 발송

## 3. 도구별 비교 분석 보고서

| 비교 항목 | Make (메이크) | Zapier (재피어) |
| :--- | :--- | :--- |
| **UI/UX 디자인** | 시각적인 캔버스 형태 (마인드맵 방식) | 직관적인 리스트 형태 (수직 나열 방식) |
| **설정 난이도** | 데이터 매핑 및 함수 사용 시 숙련도 필요 | 단계별 가이드가 매우 친절하여 초보자에게 유리 |
| **연동 서비스 범위** | 매우 광범위하며 세부 API 설정 가능 | 현존 도구 중 최대 연동 수 보유, 연결이 매우 간편함 |
| **무료 플랜 범위** | 월 1,000회 Ops 제공 (다단계 자동화에 유리) | 월 100회 Task 제공 (복잡한 구성 시 제한적) |
| **실행 로그 확인** | 데이터 흐름을 시각적으로 추적 가능 | 텍스트 기반의 성공/실패 기록 중심 |

## 4. 종합 의견

### 각 도구의 장단점 정리
- **Make**
  - **장점**: 복잡한 로직을 시각적으로 관리하기 좋고, 무료 플랜의 작업 횟수가 넉넉함.
  - **단점**: 인터페이스가 다소 복잡하여 초기 학습 곡선이 있음.
- **Zapier**
  - **장점**: 설정이 매우 쉽고 빠르며, 에러 발생 시 해결 가이드가 잘 되어 있음.
  - **단점**: Path 기능을 포함한 고급 기능을 사용하려면 유료 플랜 결제가 필수적임.

### 최종 결론
- **Zapier**는 자동화를 처음 도입하거나, 단순한 업무를 빠르게 자동화해야 하는 **비전공자 및 소규모 팀**에 적합합니다.
- **Make**는 복잡한 조건 분기가 많고, 대량의 데이터를 처리해야 하며, 비용 효율성을 고려해야 하는 **중급 이상의 사용자 및 기업**에 적합합니다.
